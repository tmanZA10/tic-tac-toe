# TicTacToe 

A simple web based Tic-Tac-Toe game  built with React and TypeScript

## Setup & Installation Guide

### Run With Docker

#### Prerequisites:
- [Docker](https://www.docker.com/get-started/)

#### Build and Run:
```Bash
docker compose up -d
```

### Run Without Docker

#### Prerequisites:
- [Node](https://nodejs.org/en)

#### Run:
```Bash
npm run dev
```

## Tech Stack
- **Framework:** React
- **Language:** TypeScript
- **Containerization:** Docker & Docker Compose
